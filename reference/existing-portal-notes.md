# Existing IT Portal — Observations
**Source:** IT team internal notes
**Last updated:** 3 months ago

## Why People Don't Use It

1. **Navigation:** 47 service categories with no search. You have to know what you're looking for.
2. **Language:** Forms use IT jargon ("incident", "service request", "change request") — users don't know the difference.
3. **No status visibility:** Once you submit, you have no idea what's happening. No email updates.
4. **Slow:** Average page load 4–8 seconds.
5. **Not mobile-friendly:** Only tested on desktop IE11 (legacy).

## Usage Stats (Last Month)

- Total portal visits: 312
- Total portal submissions: 47
- Email tickets received: 891
- Conversion rate: 5%

## What Employees Are Requesting Most (via email)

1. Software access requests (38%)
2. Hardware requests — laptop, monitor, keyboard (22%)
3. Password resets (18%)
4. New employee onboarding setup (12%)
5. VPN setup / remote access (10%)
