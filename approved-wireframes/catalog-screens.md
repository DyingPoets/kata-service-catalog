# Service Catalog — Approved Wireframes (Summary)
**Status:** Approved in Session 1 — ready for metrics + test definition

## Screen 1: Catalog Homepage
- Search bar (full-text search across service names and descriptions)
- Popular services section (top 5 by submission volume)
- Categories grid (8 categories with icons): Software Access, Hardware, Accounts, Network/VPN, New Employee Setup, Password & Security, Printing, Other
- Each category shows service count

## Screen 2: Service Detail
- Service name and description (plain language)
- Expected resolution time
- Who to contact if urgent
- Request form (or link to form)
- "Request this service" CTA button

## Screen 3: Request Form
- Dynamic per service — shows only relevant fields
- Required fields marked clearly
- Estimated completion time shown
- "Submit Request" button
- Post-submission: confirmation with reference number and next steps

---

## Design Decisions from Session 1
- No categories without search (David's pain point)
- "New Employee Setup" is a bundled service (Priya's pain point — one submission for all new hire access)
- Status page linked from confirmation email (Lisa's pain point — visibility)
